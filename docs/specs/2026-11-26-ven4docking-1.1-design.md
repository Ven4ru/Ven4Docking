# Ven4Docking 1.1.0 — спецификация

Дата: 26.11.2026. Статус: состав согласован. Дополняет спецификацию 1.0
(`2026-11-25-ven4docking-1.0-design.md`), всё, что здесь не названо, остаётся как в 1.0.

## 1. Что нового

1. **Питание** — блок с кнопками «Блокировка», «Сон», «Перезагрузка», «Выключение» и включение ПК по сети с телефона.
2. **Обновление лаунчера через ПК** — уже есть в 1.0 (установщик кладёт `apk\ven4docking.apk` + `latest.json`,
   лаунчер показывает плашку и ставит через `PackageInstaller`); в 1.1 — проверка всей цепочки и подсказка в мастере.
3. **Кнопки** — сочетания клавиш, заготовленный текст, цепочки шагов, микрофон, переключение вывода звука; шаблон Discord.
4. **Микшер** — громкость программ, устройство вывода, микрофон.
5. **Экраны программ** — экран, привязанный к программе; плашка «OBS запущен → открыть»; блок OBS через obs-websocket.
6. **Уведомления** — плитка с уведомлениями Windows, фильтр по приложениям, режимы показа.

Не входит: разблокировка ПК с телефона (телефон на стене не подтверждает личность), Voicemeeter, версия для Linux.

## 2. Общие правила

- Любое действие выполняется только по запросу привязанного телефона (токен) и только если оно разрешено
  в его раскладке или в конфиге (как запуск приложений в 1.0): кнопка питания — если она включена в блоке `power`
  этого телефона; действие — если его `id` есть в `config.actions` и в блоке `keys` раскладки этого телефона.
- Агент работает без прав администратора. Нажатия не доходят до окон, запущенных от администратора (UIPI),
  часть игр с античитом их игнорирует — редактор предупреждает в разделе «Кнопки».
- Новые блоки опрашиваются только при активной панели, где они есть (умный опрос 1.0, §3.2).
- Пароль OBS хранится в `config.json` зашифрованным DPAPI (область текущего пользователя): редактор шифрует
  (`ProtectedData.Protect`), агент расшифровывает (`CryptUnprotectData`); поле `passwordDpapi` (base64).

## 3. Конфиг (`config.json`, новые поля, все необязательные)

```json
{
  "actions": [
    {"id": "mute-discord", "title": "Discord: микрофон", "icon": null, "kind": "keys", "keys": "Ctrl+Shift+M"},
    {"id": "sign", "title": "Подпись", "kind": "text", "text": "С уважением, …"},
    {"id": "stream-start", "title": "Начать день", "kind": "macro", "steps": [
      {"launch": "obs"}, {"wait": 3000}, {"keys": "Ctrl+Alt+F9"}]},
    {"id": "mic", "title": "Микрофон", "kind": "mic"},
    {"id": "out", "title": "Наушники / колонки", "kind": "audioOut", "devices": ["{0.0.0.00000000}.{…}", "{…}"]}
  ],
  "obs": {"host": "127.0.0.1", "port": 4455, "passwordDpapi": "AQAAANCMnd8B…"},
  "notify": {"enabled": false, "wallCountsOnly": false, "nightFlash": true,
             "apps": {"TelegramDesktop": "title", "Discord": "full", "Microsoft.Office.OUTLOOK.EXE.15": "count"}},
  "wol": {"mac": "AA:BB:CC:DD:EE:FF", "broadcast": "192.168.1.255"}
}
```

- `actions[].kind`: `keys` | `text` | `macro` | `mic` | `audioOut`. `id` — как у приложений (`valid_id`).
  - `keys` — строка сочетания: модификаторы `Ctrl`, `Alt`, `Shift`, `Win` и одна клавиша (`A`–`Z`, `0`–`9`, `F1`–`F24`,
    `Enter`, `Esc`, `Tab`, `Space`, `Backspace`, `Delete`, `Insert`, `Home`, `End`, `PageUp`, `PageDown`, `Up`, `Down`,
    `Left`, `Right`, `PrintScreen`, `Pause`, `NumPad0`–`NumPad9`), регистр не важен, разделитель `+`.
    Неразобранная строка — ошибка проверки конфига.
  - `text` — до 2000 символов, вводится как Unicode (`KEYEVENTF_UNICODE`), переводы строк — Enter.
  - `macro` — 1–20 шагов: `{"keys": "…"}`, `{"text": "…"}`, `{"wait": мс 1–10000}`, `{"launch": "<id приложения>"}`.
  - `mic` — переключает «выключен» у устройства записи по умолчанию (`IAudioEndpointVolume::SetMute`).
  - `audioOut` — по кругу ставит следующее из `devices` (id устройств Core Audio) устройством вывода по умолчанию
    для всех ролей (`IPolicyConfig::SetDefaultEndpoint`, интерфейс без документации, им пользуются SoundSwitch и EarTrumpet).
- `notify.apps` — ключ: `AppUserModelId` приложения, значение: `count` | `title` | `full`. Приложения, которых нет
  в списке, не показываются. `enabled: false` — агент не читает уведомления совсем. `wallCountsOnly: true` —
  на панели только счётчики, что бы ни стояло у приложения.
- `wol` — если поля нет, агент берёт MAC и широковещательный адрес адаптера с маршрутом по умолчанию.

## 4. Раскладка (`layouts/<phone>.json`, новое)

- Новые типы блоков: `power`, `keys`, `mixer`, `obs`, `notify` (добавляются в `BLOCK_TYPES` агента и `BlockTypes` редактора).
- Экран может быть **экраном программы**: `{"id": "s3", "name": "OBS", "forApp": "obs64.exe", "blocks": […]}`.
  `forApp` — имя exe без пути, регистр не важен. Такой экран не участвует в обычном перелистывании; его открывает
  плашка, когда программа запущена, а кнопка «Назад» (и свайп вниз) возвращает на экран, с которого пришли.
  Экранов программ — до 5 (входят в общий предел 10).

| Блок | opts по умолчанию | Размер по умолчанию |
|---|---|---|
| `power` | `{"buttons": ["lock", "sleep", "restart", "shutdown"]}` | 4×1 |
| `keys` | `{"actions": []}` — id из `config.actions` | 4×1 |
| `mixer` | `{"output": true, "mic": true, "apps": true}` | 3×2 |
| `obs` | `{"stream": true, "record": true, "scenes": true, "audio": true, "stats": true}` | 4×2 |
| `notify` | `{"max": 5}` | 3×2 |

## 5. API агента (новое)

Телефон (`Authorization: Bearer`, частная сеть, как в 1.0):
- `GET /api/v1/layout` — добавляется `wol: {"mac", "broadcast"} | null` (лаунчер запоминает для включения ПК).
- `GET /api/v1/state?blocks=…` — новые ключи:
  - `audio` (блоки `mixer`, `keys`): `{"output": {"id", "name"}, "outputs": [{"id", "name"}], "mic": {"name", "muted"} | null,
    "apps": [{"pid", "name", "title", "volume": 0..1, "muted"}]}` — только сессии, которые сейчас активны или были активны за 30 с;
  - `obs`: `{"connected": bool, "error"?: "…", "streaming", "recording", "streamTime": с, "recordTime": с,
    "droppedFrames", "totalFrames", "kbps", "scenes": ["…"], "scene": "…", "inputs": [{"name", "muted", "level": 0..1}]}`;
  - `notify`: `{"access": "allowed|denied|unspecified|off", "items": [{"id", "app", "appName", "icon"?, "time",
    "title"?, "text"?, "count"}]}` — поля `title`/`text` отдаются, только если режим приложения это разрешает;
  - `running`: `["obs64.exe", …]` — только имена из `forApp` раскладки этого телефона, которые запущены (весь список
    процессов на телефон не уходит); опрос процессов раз в 5 с, только при активной панели с экранами программ.
- `POST /api/v1/power {"action": "lock|sleep|restart|shutdown|cancel"}` — `restart`/`shutdown` выполняются через
  `shutdown.exe /r|/s /t 10 /c "Ven4Docking: …"`, `cancel` — `shutdown.exe /a`; `lock` — `LockWorkStation`;
  `sleep` — `SetSuspendState(FALSE, FALSE, FALSE)`. Ответ `{"ok": true, "delay": 10}` для `restart`/`shutdown`.
  Действие, которого нет в блоке `power` раскладки телефона, — 403.
- `POST /api/v1/action {"id"}` — выполняет действие из `config.actions`; нет в блоке `keys` раскладки — 403.
- `POST /api/v1/audio {"op": "output", "id"}` | `{"op": "volume", "pid", "value"}` | `{"op": "appMute", "pid", "muted"}` |
  `{"op": "mic", "muted"}` — только при блоке `mixer` в раскладке телефона.
- `POST /api/v1/obs {"op": "stream|record|scene|mute", "name"?}` — `stream`/`record` переключают (`ToggleStream`,
  `ToggleRecord`), `scene` — `SetCurrentProgramScene`, `mute` — `ToggleInputMute`. Только при блоке `obs`.
- `POST /api/v1/notify {"op": "open", "id"}` — открывает приложение уведомления (`explorer.exe shell:AppsFolder\<AUMID>`),
  `{"op": "dismiss", "id"}` — убирает из списка на панели (в Windows уведомление не трогается).

Редактор (`/admin/*`, как в 1.0):
- `GET /admin/notify/apps` → `{"access", "apps": [{"aumid", "name", "lastSeen"}]}` — приложения, от которых агент
  видел уведомления с запуска (читаются, даже если `notify.enabled` выключен, только по этому запросу, без текста).
- `GET /admin/audio/devices` → `{"outputs": [{"id", "name", "default"}], "inputs": […]}`.
- `POST /admin/obs/test {host, port, passwordDpapi?}` → `{"ok", "version"?, "error"?}` (понятные причины:
  «OBS не запущен», «WebSocket выключен в OBS», «неверный пароль»).
- `GET /admin/processes` → `[{"name", "title"}]` — программы с окнами (для выбора `forApp` в редакторе).
- `GET /admin/wol` → `{"mac", "broadcast", "adapter", "wakeEnabled": true|false|null}` (`null` — не удалось узнать).

## 6. Как это работает в агенте

- **Уведомления**: `UserNotificationListener` (проверено 26.11.2026 на ВМ Windows 11 26H2 и Windows 10 22H2 из обычного
  exe без прав администратора: доступ `Allowed`, у уведомлений есть `AppUserModelId` и имя приложения). Опрос
  `GetNotificationsAsync(Toast)` раз в 3 с при активной панели с блоком `notify`; текст — `GetTextElements` привязки
  `ToastGeneric` (первый элемент — заголовок, остальные — текст). Иконка — `AppInfo.DisplayInfo.GetLogo` → PNG в
  `%APPDATA%\Ven4Docking\icons\notify-<хэш aumid>.png`, отдаётся через `/icons/…`. Доступ запрещён в параметрах
  Windows → `access: "denied"`, панель и редактор показывают, где включить («Конфиденциальность и защита →
  Уведомления → Доступ к уведомлениям»). Запасного пути через базу `wpndatabase.db` в 1.1 нет.
- **Звук**: Core Audio (`IMMDeviceEnumerator`, `IAudioSessionManager2`, `ISimpleAudioVolume`, `IAudioEndpointVolume`),
  опрос раз в 2 с при активной панели с `mixer` или с кнопкой `mic`/`audioOut`.
- **OBS**: клиент obs-websocket 5 (`tokio-tungstenite`), подключение держится, пока есть активная панель с блоком `obs`;
  нет OBS — повтор раз в 10 с, `connected: false`. Аутентификация — по протоколу 5 (SHA-256 + base64 соли и вызова).
- **Клавиши**: `SendInput`; модификаторы отпускаются всегда, даже при ошибке посередине.
- **Включение по сети**: агент только сообщает MAC и широковещательный адрес; пакет шлёт телефон.

## 7. Панель

- `power`: кнопки по `opts.buttons`; срабатывание — удержание 2 с (кольцо заполняется), отпустил раньше — ничего.
  После `restart`/`shutdown` — полоса «Выключение через 10 с · Отмена» поверх панели (отмена шлёт `cancel`).
- `keys`: кнопки действий; у `mic` — состояние из `audio.mic.muted` (красная, когда выключен); у `audioOut` —
  имя текущего устройства.
- `mixer`: ползунки громкости программ (касание и перетаскивание, отправка не чаще 5 раз в секунду), выключение звука
  программы, выбор вывода, микрофон.
- `obs`: «Стрим» и «Запись» (горят, когда идут, с временем), сцены кнопками (текущая подсвечена), источники звука
  с выключением и уровнем, строка «потеряно N кадров · M кбит/с». Нет связи — «OBS не подключён» и причина.
- `notify`: последние `opts.max` уведомлений (иконка, приложение, время, заголовок/текст по режиму, счётчик);
  касание — открыть приложение на ПК, свайп влево — убрать. Ночью, если `nightFlash`, новое уведомление поднимает
  яркость на 5 с.
- Экраны программ: плашка внизу «<Имя экрана> · открыть», пока программа из `forApp` есть в `running`;
  исчезает, когда программы нет. На экране программы — кнопка «Назад».
- Экран «ПК не отвечает»: кнопка «Включить ПК», если лаунчер знает MAC (`DockAndroid.wake()`).
- Демо-режим (`?demo=1`) получает примерные данные для всех новых блоков.

## 8. Лаунчер

- Мост: `DockAndroid.setWake(mac, broadcast)` (панель передаёт из раскладки, лаунчер хранит в `Prefs`),
  `DockAndroid.canWake()`, `DockAndroid.wake()` — магический пакет (6×`FF` + 16×MAC) на UDP 9 по адресу `broadcast`
  и на `255.255.255.255`, три раза с паузой 300 мс.
- Свой экран «ПК не отвечает» (страница не загрузилась) тоже показывает «Включить ПК», если MAC известен.
- `versionCode` растёт на 1, `versionName` — `1.1.0`. Обновление 1.0.0 → 1.1.0 через ПК проверяется на эмуляторе.

## 9. Редактор

- Новый раздел **«Кнопки»** (между «Приложения» и «Серверы»): список действий, добавление по типу, запись сочетания
  нажатием клавиш, редактор цепочки шагов, выбор устройств для `audioOut` (`/admin/audio/devices`), шаблон
  «Discord» (два действия: `Ctrl+Shift+M` — микрофон, `Ctrl+Shift+D` — звук; подсказка, что сочетания должны совпадать
  с настройками Discord), предупреждение про окна администратора и античиты.
- Новый раздел **«Уведомления»**: переключатель «Показывать уведомления на телефоне» (`notify.enabled`), состояние
  доступа Windows с кнопкой «Открыть параметры» (`ms-settings:privacy-notifications`), список приложений
  (`/admin/notify/apps`) с режимом `скрыть | счётчик | заголовок | текст целиком`, «На стене только счётчики»,
  «Ночью подсвечивать новое уведомление».
- **«Настройки» → «OBS»**: адрес, порт, пароль (шифруется DPAPI), «Проверить подключение», подсказка «OBS → Сервис →
  Настройки WebSocket-сервера».
- **«Настройки» → «Включение по сети»**: MAC и адрес (`/admin/wol`, можно поправить), состояние «включение по сети
  разрешено в Windows» и подсказка про BIOS/UEFI («Wake on LAN», «Power On By PCI-E»).
- **«Экраны»**: палитра с новыми блоками; настройки блоков (`power` — какие кнопки, `keys` — какие действия,
  `mixer`/`obs` — что показывать, `notify` — сколько); у экрана — «Экран программы» с выбором из запущенных
  (`/admin/processes`) или вводом имени exe.
- Мастер подключения: на шаге настройки для Android 8+ — подсказка разрешить Ven4Docking установку приложений
  (нужно для обновления лаунчера через ПК), команда `appops set ru.ven4tools.docking REQUEST_INSTALL_PACKAGES allow`
  с проверкой результата.

## 10. Проверки

- Агент: `cargo test` — разбор сочетаний клавиш и шагов цепочки, проверка конфига с новыми полями, отказ 403 для
  действий/кнопок вне раскладки, фильтр уведомлений по режимам (на подставном источнике), протокол аутентификации
  obs-websocket (пример из документации), MAC → магический пакет.
- Панель: `npm run lint` (Chrome 51), сборка; демо-данные новых блоков.
- Лаунчер: юнит-тест магического пакета.
- Редактор: юнит-тесты моделей (действия, режимы уведомлений, DPAPI туда-обратно), сборка без предупреждений.
- Ручной прогон: ВМ Windows 11 и Windows 10 по одной — уведомления, клавиши в Блокноте, блокировка и выключение
  с отменой; эмуляторы Android 7 и 10 — новые блоки, плашка экрана программы, обновление лаунчера 1.0.0 → 1.1.0
  через ПК; OBS — на ВМ, если владелец разрешит скачать OBS; живой realme — только по слову владельца.

## 11. Выпуск

Версия 1.1.0 у агента, редактора и лаунчера; выпуск и публикация — только по слову владельца.
